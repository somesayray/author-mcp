# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-11-07

### Added
- **`CR-CONTEXT-SQUEEZE-001` (Compress Context with SuperSqueeze — CANONICAL)** in `AGENTS.md`: agents compress bulky context through SuperSqueeze (`hath0r squeeze` / `SuperSqueezeBot`) before it enters a context window or prompt.

## [0.1.0] - 2026-10-28

### Added
- **`CR-CLI-ENTRY-001` (Start with the CLI — CANONICAL)** in `AGENTS.md`: agents check the `hath0r` operator CLI first on every request, offer to register missing capabilities, and require docs before code.
